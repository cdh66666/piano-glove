# 钢琴手套 · Piano Glove

这是钢琴辅助训练手套的 Windows 软件与 ESP32 固件源码。桌面软件包括手指训练、曲库、PDF 原谱识别与校对、练习曲谱传输和读谱教程。

## 当前软件

- 自动检查无提示的音和人工确认的音合并计算校对进度；识别可能漏音或出错，仍可对照原谱修改。
- 在曲库中播放或发送曲谱时，软件会把保存的修改合并回完整曲谱。导入 PDF 与软件自带曲谱分别保存。
- 启动时不会自动恢复上次退出的转换队列；同一次运行中切换页面不影响正在进行的转换。
- 未印指法的音可能使用软件估计的练习指法，使用时可在校对页检查和修改。

## 仓库与资源

`host/` 是桌面软件和识谱代码，`firmware/` 是主控固件，`tools/` 包含打包与离线模拟工具。用户的校对记录、设备数据、原谱 PDF 和预计算识谱缓存未包含在公开仓库中。完整软件自带曲谱需要另行取得有权使用的 `host/assets/score-library/` 资源及其 `manifest.json`；仅克隆此仓库无法重建包含 100 首曲谱的交付程序。

Windows 单文件程序没有放入 Git 仓库；打包时使用 WebView2，目标电脑如未安装对应运行组件需要另行安装。手套连接所需的 USB 驱动取决于目标电脑的配置。

## 构建与验证

安装 `tools/requirements-runtime-build.txt` 中的依赖并准备上述曲谱资源后，可在 Windows 使用：

```powershell
python tools/build_customer_runtime.py --single-exe --lightweight --work <构建目录> --output <输出文件.exe>
```

界面、识谱与设备通信的测试位于 `host/tests/`；部分历史界面模拟测试的假 DOM 需要适配现版界面。软件识别和离线模拟结果不等同于实物演奏或人工逐音验收。
