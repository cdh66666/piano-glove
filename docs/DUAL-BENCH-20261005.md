# 双型号台架验证（2026-10-05）

测试时两副手套均未穿戴。STS3032-C001 在 COM3 / 8123，SC09 在 COM27 / 8124。两个调试台固定各自串口，错误串口连接返回 409；分别断开、重连后均 armed=0，不恢复旧动作。未执行 ID 修改，已有校准数值保持不变（SC09 的拇指文字标签与实际用途统一）。两套均使用 ID2 弹奏拇指，ID1 保持姿态。

## 动作与曲目

两版单指、组合、交替均台架通过。STS 三种动作约 2.35 / 1.89 / 2.04 秒；SC09 约 3.83 / 3.23 / 3.23 秒。

三首右手曲目均通过。最新 STS 南瓜布吉舞约 5.09 秒（执行器实测）、波尔卡 4.0 秒、阿拉伯风 3.6 秒（UI）；SC09 三首 UI 连续执行分别 7.6 / 7.0 / 7.1 秒。曾发现外部测试与空闲 UI 轮询并发产生一次写入延迟停机，改用真实 UI 复测通过，未删除延迟检查。

曲目到位允许沿指令方向完成本次距离的 50%，并保留无反馈、错误方向、停滞及硬限位检查。测速不采用半程判定。最后抬起后进行至多 200 ms 的稳定观察再关闭力矩，不重复发送端点目标；最后一次通信可略超观察调度时长。

STS 校准范围外反馈回弹余量统一为 min(114 counts, 行程/4)，不扩大目标，也不越过硬件限位；初始使能目标到位仍严格。SC09 反馈范围余量保持 6。
