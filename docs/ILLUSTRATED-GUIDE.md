# 图解使用指南

## 1. 先看完整流程

![钢琴手套使用流程](images/workflow-20261021.svg)

先启动本机桥并选择主控，再确认编号。已有完整 ID1～6 无需重编；更换佩戴者只需重新测量舒适行程。

## 2. 中断后保持接线

![六台编号中断恢复](images/enrollment-resume-20261021.svg)

点击“继续编号（保留进度）”。程序确认现场地址与保存进度后继续，支持临时编号和正式转换阶段的中断。若主控 USB 离线只恢复 USB；不要先把已编号的六台全部拔下。

全新的同地址舵机仍按提示逐台接入。总线地址不能区分同一 ID 的多台实体，不能用“继续”跳过首次单台接入步骤。

## 3. 编号完成后校准

![六台已编号的真实调试界面](images/debug-console-20261021.png)

上图为 2026-10-21 续编结束后的实际页面。记录每根手指的完整舒适往返，并自然放松；某一根需要重测时只重校该根。SC09 / STS 安装流程以页面识别结果为准。

## 4. 训练和曲目界面

![五指状态与范围](images/finger-training-20261015.png)

![原谱跟随及反馈](images/score-follow-20261015.png)

这两张为 2026-10-15 历史实机开发截图。ID2～6 为五指按压轴，ID1 为拇指姿态轴。界面中的数值只属于当时那副装置，不能复制成其他手套的行程。

## 5. PDF 要逐项校对

![原谱下方的指法与时值确认](images/score-review-20261014.jpg)

2026-10-14 的校对界面：对照原谱检查每项右手指法和持续时间，再导出。缺失、疑点或不支持的谱式需要人工处理。

## 6. 看不懂谱，先找到一个键

![找到两个黑键左边的中央Do](images/read-score-central-do-20261015.png)

![把琴键和谱中音符对应起来](images/read-score-note-key-20261015.png)

2026-10-15 教程界面。先找中央 Do，再对应谱中的圆点；教程播放仅演示声音和画面，不会驱动电机。
