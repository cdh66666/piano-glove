# 钢琴手套：大模型与接手人员使用入口

版本：2026-10-05。适用本仓库当前双型号本机调试台。先读本文，再读 README；旧日期的记录是历史证据，不能覆盖本文的当前流程。本文是项目操作说明，不授予未获用户授权的运动、烧录或文件发布权限。

## 1. 交付包与启动

完整交付包包含功能演示、装配视频、模型预览、纯组装图文教程（PDF/DOCX）、贵舵机物料表、装配 STEP，以及 `源码与调试台/piano-glove/`。先看 `0-功能调试&效果演示视频--优先看这个.mp4`；机械装配按图文教程，后续软件操作按本文。物料表标注贵舵机，不要当作便宜版完全相同的物料表。

电脑需 Windows、Python 3（加入 PATH）、CP210x 串口驱动。解压源码到可写目录，双击 `host/start-debug.bat`；首次会安装 pyserial，需要联网。打开 `http://127.0.0.1:8123/web_piano_glove.html?simple=1`，保留启动命令窗口。关闭该窗口会停止串口桥。单独打开 HTML 或用普通静态服务器不能控制硬件。

两副手套接在两个独立主控上：双击 `host/start-dual.bat`。恰好两个 CP210x 主控时自动选择；更多设备时在源码根目录运行 `host\start-dual.bat COM3 COM27`，将示例端口换成实际端口。两个页面分别使用 8123、8124；端口顺序不代表型号。页面顶部可手动切换 COM，已被另一调试台使用的设备会转到对应页面。不要再开一个桥抢占串口。

USB 给主控通信；舵机按现有装置使用独立 5V/5A 电源。不要因为型号支持其他电压而擅自改变现有供电。一条舵机总线使用同一型号，不能混接两个系列。

## 2. 先识别，后操作

检查实时 INFO 的 profile、range、在线数量、固件能力和 armed 状态，不能靠 COM 号或 AP 名判断是哪副手套。六台应在线；固件为本仓库 PIANO_GLOVE_2 v2.2.4。版本号相同也要检查同步组动作能力。连接、重连、烧录后不自动恢复之前动作。

| 实际型号 | 配置族 / 位置量程 | 校准安装 | 展示速度命令 |
|---|---|---|---|
| SC09（便宜版） | SCS / 0–1023，300° | 先拆臂、中位安装，再采行程 | 1000 |
| STS3032-C001（贵版） | STS / 0–4095，360°编码 | 不走 SC09 拆臂中位步骤，按页面建立原点后采行程 | 8000 counts/s |

这些是控制参数，不是保证达到的实物速度。STS 编码跨零由软件处理；不能据此推断机械可以无限旋转。若当前跨零范围未通过运动检查，先按提示重新建立原点/校准，不绕过检查。

## 3. 固定映射与按下方向

| ID | 实际用途 | 是否弹琴按键 | SC09 按下端 | STS 按下端 |
|---|---|---|---|---|
| 1 | 拇指外展/内收，演奏摆位 | 否，保持已设置的演奏姿态 | min | min |
| 2 | 拇指落键 | 是 | min | max |
| 3 | 食指 | 是 | min | min |
| 4 | 中指 | 是 | min | min |
| 5 | 无名指 | 是 | min | min |
| 6 | 小指 | 是 | min | min |

min/max 指校准有效行程两端。结构和型号决定方向，不按“校准第一次往哪走”或“最后放松在哪”猜方向。程序在采集和恢复已有校准时核对固定方向；恢复纠正只修改方向并保留端点，不驱动舵机。纠正失败不要继续动作。

用户试过 ID1+ID2 耦合推动拇指，已决定取消：交付继续只用 ID2 落键，ID1 保持摆位。不能把实验改回默认。已有 ID1–6 无需重新编号；只有更换未编号舵机时才使用独立编号流程，按页面逐台接入，禁止一次接全再批量猜 ID。

## 4. 校准与验收顺序

1. 停止动作，确认连接正确型号。新佩戴者、重新装臂、换舵机后重新校准，不能复制别人的端点。
2. SC09 按安装页先拆下舵机臂，再点击中位定位保持，按示意图装回；STS 跳过此安装步骤，按页面的原点建立流程操作。
3. 采集每轴真实舒适行程：完整往返一次，最后自然放松。方向自动使用上表，待机中点取行程中间。采集保存全轨迹并过滤瞬时离群值；不能直接把所有原始最大/最小值当端点。
4. 某轴不合适时用其位置条下面的单独校准按钮，只重采该轴。全部重来用完整重新校准。普通四指行程明显大于其他指时页面会建议重校，建议不会自动缩范围；拇指本来较短，不据此强行扩大。
5. 第二页显示动作与测速全界面。分别点击单指、组合、交替，只执行所选项。五指同步测速按 20/40/60/80/100% 工作行程测量；柱上是五指频率平均，下方默认显示当前档各指 Hz，另列整组同步 Hz。失败/未测不能填造频率。
6. 第三页查看三首右手原谱节选及真实谱图，逐首演奏，核对屏幕指法与实际动指。弹奏使用抬起↔按下，不逐音回中位。ID1 使用已设置的演奏姿态。
7. 软件检查、摘下手套台架测试与用户穿戴体验分别记录。台架完成后再由使用者确认穿戴方向、舒适度、实际落键；重新连接不能当作已完成穿戴验收。

贵版满档为记录行程中央 90%（两端留余量），便宜版使用其工作端点；百分比均相对工作行程。反馈略超校准范围的 15% 不强制回范围，这不扩大目标或硬件限位。普通动作到位容差为 SC09 35 counts、STS 等效 114 counts；曲目允许本次目标移动距离完成约一半后继续，提高连续性，仍保留通信失败、错误方向、停滞等停止条件。测速不能沿用曲目的半程判定冒充完整往返速度。

## 5. 烧录与故障处理

- 正常使用不必反复烧录。确需更新时先选正确 COM，再点击一键烧录。关闭弹窗不会取消后台任务，顶部进度可重新打开；完成后自动检查连接，失败保持暂停。两台不要同时烧录同一个构建目录。
- 手动构建需 PlatformIO：在源码根目录 `pio run -d firmware`；指定实际板端口烧录 `pio run -d firmware -t upload --upload-port COM3`。硬件目标由 `firmware/platformio.ini` 固定。不要擦除 NVS 解决普通连接问题。
- 离线：确认启动窗口仍在、电源/USB/驱动正确、端口未被其他程序占用；重新连接后先读状态，不恢复旧目标。
- 方向反：先核对型号和 ID2 落键映射，再确认页面已完成固定方向纠正。不要反转所有轴，也不要用先动方向重新推断。
- 范围异常：查看本机 `host/calibration_recordings/<COM>/` 的轨迹与过滤记录，重采受影响轴；保留其他轴。记录属于本副手套，不作为通用交付参数。
- 曲目不到位：确认校准/方向/工作幅度和速度档，查看真实反馈。曲目容忍度与测速规则不同，不能删除通信保护换取“完成”提示。
- 急需停下：点击页面停止，确认 SAFE/armed=0；遇到阻力或异常先停止处理，不用连续重试运动掩盖错误。

## 6. 大模型维护规则与证据

先读实时状态，再做用户授权的操作。前端修改只需刷新；只有后端实际变化才重启桥，重启前核对所属项目、端口、PID，重启后检查健康与连接，不恢复动作。不要调用修改 ID 的流程做普通回归。源码更新、固件编译、软件测试通过不等于已经烧录或实机完成。

只读接口：`GET /api/status`、`GET /api/firmware`。串口指令入口 `POST /api/send`（JSON 包含 `cmd`，可设置 `quietMs`、`timeoutMs`）；常用只读命令 INFO、CAL STATUS、STATUS_ALL、POSALL。连接入口 `POST /api/connect`（port、baud=115200），断开 `/api/disconnect`。运动参数及校准写入应由调试台现有执行器协调，不能与页面轮询并发运行另一套外部运动脚本。
