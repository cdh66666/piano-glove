# SC09 最新功能适配 · 2026-10-01

## 已完成的软件适配

- 自动识别、编号与换型校准保留双型号分支。SC09 使用 0–1023、大端位置寄存器、默认展示速度 1000；不会套用 STS 的 4095、8000 或 CAL ORIGIN。
- SC09 保留拆臂中位安装（512），跨零采样可记录，但跨零运动不放行，需通过安装角度让工作行程落在可控区间。
- ID1 为拇指外展/内收，ID2 按压拇指，ID3–6 对应食指至小指。曲目中 ID1 保持抬起端；五根按压轴只在抬起与按下端之间运动。普通动作/五指测速保持 ID1 中点。
- SC09 满档保留原校准端点各内缩 6 计数；STS 仍为中央 90%。同步组合使用一次 GROUP 写入，不降级成逐台运动命令。
- 普通动作到位容差 35；小幅测速保留可分离的端点判定窗，防止尚未完成往返就累计频率。到位误差与校准边界检查不同：不把反馈容差当成扩大命令行程的授权。
- 修复 SC09 低速/长行程的固定 1 秒超时：支持 KEEP 的固件按行程计算有界等待并确认续期。反馈释放、堵转、超时仍停止；固件 1200ms 失联卸力不变。
- 三首原谱使用按型号选择的计划：SC09 暂恢复每首 6.4 秒（75 / 37.5 / 37.5 BPM），标记待本次实测；STS 保持 4 / 3 / 3 秒（120 / 80 / 80 BPM）。显示、时间轴、执行共用计划；同拍边界统一取整，切换型号不重复缩放。
- 五指同步测速仍提供全程、半程、20% 行程，显示平均频率，并可展开各指与同步频率。
