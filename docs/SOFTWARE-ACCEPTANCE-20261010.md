# 软件实现和验收记录

> 公开说明：本文保留原验证时点的历史事实与未验证项。原始设备日志、Flash 备份、客户运行包和本地验证记录未随仓库打包；下文的记录目录及文件名用于追溯，不是本仓库的下载链接。当前功能入口以仓库首页为准。

本轮按用户要求先实现、测试，再修改软件协议；此文件持续记录实际结果，不能把计划当成通过。

## 当前实机

- 用户确认：手套已摘下，贵版 STS3032-C001 接在电脑 COM3，外接电池稳压 5V。
- 便宜版 SC09 在甲方处；本轮只做软件适配和协议/型号模拟测试，实机待甲方远程验证。
- 首次只读查询：六台在线、校准有效、力矩关闭。原固件 2.2.4。
- 旧 INFO 打印固定 AP 名称及地址，源码没有 WiFi 服务；这不能作为热点正常的证据。
- 原调试台前端 227 项回归测试通过。
- .pgl 编解码 7 项测试通过；真实设备已写入100份测试曲谱，每份1000音符，共100000音符。原始文件1612800字节，压缩文件714427字节，文件系统使用753000字节，剩余565001字节。不能据此保证100首任意长度的整曲。
- 刷新固件并重启后，通过真实热点逐字节回读100份文件，全部与原始文件一致；损坏CRC文件及第101个槽位被拒绝，原文件保留。
- 此前30份PDF、116页已批测：29份矢量谱可提取候选，1份扫描谱不能自动识别。原谱仍需人工校对，不宣称全部自动识别正确。三份右手节选已核对并导出。
- 手机已实际打开热点页面并操作，最初反馈交替训练失败。反馈修复版已实机重测通过；初连空连接等待由约5.07秒降至最终0.04秒。自动弹页所需DNS与三类探测重定向已通过，手机重连弹页和脱离USB控制尚待用户验证。
- 独立POSALL核查：无名指从1695回到2376目标，在0.389秒读取到2375；旧大STATE却曾保留1694。原运动测试因此记为失败，不能作为机械卡住或训练通过的证据。
- 基线串口证据：`本地验证记录：software-20261010/baseline.json`。
- 电源总电流：缺少外部测量工具，暂未测；舵机 current 字段不是电源总电流。
- 新版35项记录的无穿戴训练测试通过：逐指、组合、交替、50%/100%保持、停止和不发KEEP的2.3秒失联停止；真实位置样本最大年龄20毫秒。真实有效健康样本最低电压原值46，最高温度32°C，不代表电源峰值电流。
- 三份人工核对的右手节选各以100%和150%速度播放，共六次正常完成；USB上传及回读字节一致。网页实际点击逐指、组合、交替也完成，串口记录无ERR LIB。
- 最终界面镜像911008字节，SHA256 `1b7028acbc5c87225a4b51e32ae55e687ed6fcc3036382cfcad9c408be35a3d1`。与完成动作测试的镜像相比只改变嵌入界面，运动源码一致；刷入校验通过，校准和曲库保留。
- 桌面PDF补录功能已加入，扫描谱或漏音可手录后导出；扫描自动识别仍未支持。34项后端测试、30项页面行为测试通过，包含真实Python手录导出及空白拒绝。
- 新位置有效性字段的后台重载被自动审批拦截，未绕过。运行后台已支持短状态及真实年龄，但尚未重载最后加入的pv展开字段；本次实机脚本通过原始LIB STATE验证pv并用最新解码器展开，不能宣称运行中的HTTP已加载这项字段。固件直连热点的完整HTTP状态不受此影响。
