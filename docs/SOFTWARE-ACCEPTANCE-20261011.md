## 本轮修正

1. 修复设备停止后训练循环自行继续、快速切换模式旧响应干扰、播放失败未清理、关声启动再开声无声，以及不同PDF沿用旧范围。
2. 同一个PDF重新打开原谱保留已核对和补录内容；所有修改取消范围确认，空白或未核对候选不能导出。
3. PDF生产解析和预览改用PDFium并共享线程锁；客户运行包不依赖PyMuPDF。新旧后端5个时值差异经原图核对修正，仍保留人工复核标记。
4. 较长曲谱在删除替换后恢复写入曾复现主控重启。旧三层固定栈占5232字节；移出大栈缓冲并使用16KB loop栈，实际USB重测通过。日志回溯损坏不能证明唯一根因，不把栈压力推断当成GC根因结论。

1. 贵版ID2拇指按下方向改为低值端；ID1仍保持演奏姿态。同步修正设备NVS方向及新旧页面固定方向表，六台校准上下限、中点和epoch16保持。真实按下目标1945、抬起目标2397均有实际位置反馈，ID1目标2237保持。
2. 曲谱不启动曾实际返回小指ID6位置2672超出允许余量上限2601，旧界面提示不明显；现在错误就近显示，实时水位说明具体范围。另一启动阻塞由音频解锁Promise未完成造成，音频解锁不再阻塞设备启动。
