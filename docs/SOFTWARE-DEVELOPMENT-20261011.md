# 钢琴手套正式软件开发

> 公开说明：本文保留原验证时点的历史事实与未验证项。原始设备日志、Flash 备份、客户运行包和本地验证记录未随仓库打包；下文的记录目录及文件名用于追溯，不是本仓库的下载链接。当前功能入口以仓库首页为准。

本轮按已确认功能开发，不再修改既定范围，也不把旧软件测试结果当作本轮新增功能验收。

范围：电脑数据线操作、手机热点浏览器独立操作、电脑版带指法PDF转换与手动复核校准、手套100首曲库、单指/组合/交替训练及未动指保持、右手曲谱跟随与整体速度调整、专门播放页、长音/休止/和弦和声音同步。本报告只记录技术范围与验证结果。

本轮已实现并验证：

- 手机热点：显式DHCP DNS、支持EDNS的DNS响应、Android及各品牌/iOS/Windows检测入口、未知HTTP检测路径跳转。用户已在荣耀系列手机上实测：断开后直接点选热点，不打开浏览器、不输入网址，自动弹出控制页。后台记录检测域名为荣耀 `hihonorcloud.com`，37次探测、4次落地请求；协议覆盖不能替代其他品牌的物理弹页测试。
- 播放：独立演奏页、右手指法、实时水位、音符进度、真实原谱及定位。实际GUI完成六小节26音；完成保留满进度，停止保留当前位置。
- 声音：独立20ms本地调度、设备时钟RTT修正、暂停和未处理音符边界、长音、和弦、立即静音。118项前端与声音/原谱包测试通过；用户确认手机动作和声音正常、结束安静，声学延迟尚未定量测量。
- 原谱随文件：`.pglpack` 存放原始PGL、校验索引和真实PNG。手机导入后，原谱存在浏览器，手套只收紧凑PGL。实际波尔卡原谱包179208字节，经Python导出、JavaScript读取和GUI上传，设备读回544字节与原PGL逐字节相同。没有关联原谱时明确显示音符进度，不替换成假原谱。
- 传输与控制：384字节分块、CRC、事务替换与回滚、页面控制身份；实际1000音符文件分块读回、坏CRC拒绝、断传保原文件通过。76项后端会话/传输测试通过。内部准备、失败清理和关闭页面只释放自己控制的动作。电脑程序退出改用原子 `LIB RELEASE`，跳过Wi-Fi拥有的动作或准备；红色停止保留原停止行为。启动器7项生命周期检查通过。
- 固件：最新实机镜像983456字节，SHA256 `6970b42cef7263f33002dd2011e9593a6549be12cfa71b5a818f941cfc5dc120`。应用区域0x10000写入并验证，校准逻辑记录和100槽索引保持，重连无自动动作。17组固件检查通过，42文件版本清单和5份实际嵌入资源一致；HTTP等待期间继续反馈和保活。
- 转换器：修复几何旗形、时值、完整起拍、8va、复杂声部、密集低音跨谱表和交叉平行符杠，复核后的连音、反复和房号展开。独立核验146/146四字段正确，含145印刷指法及1个正确保留空值；原谱人工初始标注修正另存来源与图像核对记录。不按文件名或金标填答案。84项测试通过；字段完整从6194/13646变为7753/13684，候选归属调整改变分母，不能当准确率。
- 运行包：r5 ZIP79711860字节、443文件，SHA256 `ef18bdd60e2eaf7f1d2f3b8d740f80deb7717dc0b6efd93c6b758ec67b4f9f10`。冻结EXE验证实际PDF和PGL、9项页面资源；包内固件为上面同版镜像，含三份真实原谱节选的PGL与随谱包。不含CAD、BOM、完整项目/固件源码；未向客户发送或公开推送本轮软件。

仍需验证：

- 全批PDF自动识别的90%目标尚未证明。30份116页无解析异常，但字段完整覆盖与独立准确率不同；缺失值保留并要求人工复核，未复核不准导出。
- 其他手机品牌的实际弹页、手机真实原谱包导入、声学延迟。手机动作/声音确认是在本轮重刷期间收到，具体执行时刻未另行同步；不冒充新原子释放分支的物理互不干扰测试。
- USB和电池全部断开的冷启动、穿戴时未动指保持效果、客户电脑和远程廉价实物。

历史100份各1000音符实际设备存储与逐份读回通过，列表存储合717081字节、文件系统使用753000字节。当前1—4槽为真实节选，5—100为容量测试文件；100槽已占用不等于100首真实曲谱。固件重启保留已记录，全断电未验。外接5V电池供电未改变，本轮记录原始舵机电流和健康数据时间；没有外部总电流表，原始current=0不能算电池输出总电流为0。
