- **连续节奏**：曲谱和声音按设定速度推进；软件训练/曲谱路径的校准范围偏差只提示，手指未到位不暂停曲谱、不推迟后续音符。重复同指音按计划预释放，结束也不等待最后一个动作到位。

- **批量校对限制**：只看疑点时仅确认显示疑点；无定位、无效框、缺字段或未知声部不允许批确认。识别防重入及失败保留旧校对进度继续有效。
- **极简教程**：按需打开图示教程，涵盖右手指法、音高、拍子与时长、休止、和弦、连线及反复。已有图示音高和节奏校验保留。
