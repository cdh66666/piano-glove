# 手机无线操作修复 · 2026-10-22

已更新电脑端和板内同源的完整测试台；保留三指 CDE/FGA《小星星》、连续同指加高抬指、免密热点、校准和原曲库。

## 无线播放

源码可复现的误停路径：前台超过1秒没收到反馈即终止本地播放，单次STATE或KEEP网络异常也立即发送停止；固件原先所有控制模式均只有2秒KEEP间隔。这些是已修正的触发路径，未取得用户历史手机中断的实际停止日志，不能断言是唯一原因。

手机无线曲谱播放现对可识别的短暂网络错误先重试，前端最多4秒无反馈后停止；板内Wi-Fi曲谱KEEP最大间隔5秒。手动训练、组合训练及USB仍保留原有严格停止行为。硬件、反馈、电压、温度、控制权错误均不作为网络抖动忽略；真正停止后重连不自动恢复。手机曲谱反馈轮询降至120ms，控制请求不随滑动每个像素发送。

## 文件选择和上传

保留直接点击的原生文件框，取消Android对未知文件扩展名的不可靠筛选。所有输入在写板前检查PGL头、音符和CRC；带原谱包继续校验图片与曲谱的关联。选中、取消和文件名均有明确显示。

系统热点登录小窗是否提供文件选择器由手机系统决定，网页不能补出原生选择器。已提供默认折叠的“选文件没反应？”帮助，可复制地址或尝试打开浏览器。可靠操作入口为手机正常浏览器的 http://192.168.4.1/software.html 。未将电脑浏览器测试宣称为所有手机系统小窗验证通过。

主条加宽且步长1%。拖动、聚焦主条或点击当前百分比会展开大号精调条，范围为当前值附近±25个百分点，带±1%按钮和数字输入。拖动仅预览，松手才沿原命令队列提交；保留50%–1000%范围。
