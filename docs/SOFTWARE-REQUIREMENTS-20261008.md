# 钢琴手套正式软件范围（2026-10-08）

> 公开说明：本文保留原验证时点的历史事实与未验证项。原始设备日志、Flash 备份、客户运行包和本地验证记录未随仓库打包；下文的记录目录及文件名用于追溯，不是本仓库的下载链接。当前功能入口以仓库首页为准。

来源：用户本轮软件要求；延续已确认的双型号、右手五指、ID2 落键、ID1 摆位、固定方向和工作行程规则。此文是开发与验收范围，不能当成现有版本已完成的功能表。

## 产品与连接

- 电脑版：训练、曲库、节奏/声音、设备管理；另有仅电脑版的带指法谱转换器。
- 手机版：浏览器连接手套自身热点，打开设备页面，不依赖电脑运行串口桥，不要求公网。
- 电脑通过数据线传文件，手机通过热点传文件；设备采用同一个 .pgl 曲谱文件，不能两个通道各有一种格式。
- 电脑转换完成可发送到设备，或把文件发给手机再上传。设备保留至多 100 首，支持列表、选择、删除、替换、剩余容量；设备断电后仍保留。
- 没有请求后台发声或锁屏控制。手机首次点击开始解锁声音；页面退后台/锁屏时应检测并停止当前训练，不能只留下舵机继续。

## 训练

手指独立训练、组合与交替训练、曲谱跟随训练是主要用途。动作速度与节奏速度分开：整体曲谱速度按倍率缩放起音、时值和休止，舵机使用对应型号已验证参数；不能通过加快节奏假称舵机速度提升。

未参与的手指主动保持其本次训练的抬起参考位置，ID1 保持拇指姿态，不随被训练手指联动而失能。保持力度可调，但位置保持不等于精确恒力；目前机械与舵机反馈尚不能保证完全消除人手肌腱耦合。验收必须观察未动作指偏移及舒适度，不只检查目标指到位。

固定映射：指法1→ID2；指法2/3/4/5→ID3/4/5/6。ID1 不作为第六根弹奏手指。校准、方向、90%工作范围等沿用当前双型号规则；不恢复已取消的 ID1+ID2 耦合落键。

## 曲谱转换与声音

用户已确认只支持此前提供的同类带指法 PDF，不支持拍照图片。实际识谱路径待约定样本验证。识别右手音高、印刷指法、音符时值、休止、和弦、连音/延音与拍速。MIDI 本身通常没有原谱印刷指法，不能冒充识别原指法。

转换器必须提供原谱对照和修改页：低置信/缺失指法不能默默猜成已核对；用户确认后才能导出可运行文件。左右手区分单独验收。

设备文件包含音高、指法、起音、持续时值、力度，不能只存指法和延时，否则无法还原声音。仅收右手五指范围；和弦保留同时起音，重复指法重叠须纠正。

声音从电脑或手机输出，与设备同一曲谱时间轴同步。长音使用 note-on/note-off 与延音包络，不循环反复起音；钢琴的真实自然衰减可保留。手机无线同步以设备时钟为基准，测量延迟并校时，不能在每个音上等待一次网络往返。

## 文件、存储与执行

.pgl v1 的编码器/解码器定义在 host/score_codec.py。固定128字节文件头，每个音符16字节；标题UTF-8，携带CRC32。USB和热点发送相同字节；接收时先写临时文件、校验，再原子提交。断开不能留下半首可演奏文件。

每首1000个音符约16128字节，100首约1.54MiB；每首500个音符约8128字节，100首约0.78MiB。这是格式计算，不是已验证容量。当前4MB主控默认文件分区0x160000约1.38MiB，固件/界面与文件系统余量也需预算；需通过编译大小决定分区或单首上限，不能承诺100首任意长度。

运行事件由设备定时器调度并分组同步写入；USB与Wi-Fi只有一个控制权，互相冲突时报忙，不能同时驱动。文件上传在停止状态进行。停止、失联、重启不恢复旧演奏。支持共享索引查询及有序分块传输；具体协议在实现时版本化。

## 现状与交付验收

现有：本机串口调试、双型号校准、动作与五档测速、三首右手示例、旧MIDI导入/发声链路。缺少：设备热点接口、设备100首库、统一文件固件解析及设备执行、正式移动界面、PDF/照片原指法识别、未动作指保持训练验收。

实现顺序：统一文件与校验 → 设备存储/双通道传输 → 设备执行及独立保持 → 电脑/手机训练和同步声音 → 识谱转换与原谱核对 → 两型号摘下台架与穿戴验收。

验收包含：100首容量/断电保留/满容量提示/坏CRC和断传；同文件USB与热点导入一致；全局倍速保持时值比例；长音/休止/和弦；右手指法映射；未动作指偏移；两型号校准方向；通信中断与停止；手机声音解锁和前后台。

下次供电测试按用户要求记录电源输入总电流（平均/峰值）、压降与供电规格，覆盖待机、单指、五指同步、曲目。没有外部测量工具时明确缺测，不把舵机反馈 current=0 当作总电流。

原有正式交付包和客户运行包仍是2026-10-05版本；本轮开发文件未等同于更新这些包。源码仓库按用户要求暂时公开，客户包继续不含正式核心资料。
