## 〇、物理急停 = 外接电源断电（已定案）

样机由**外接 5V/5A 适配器**供电，所以「物理急停」就是**硬切断动力电**：
拔插头，或（更推荐）**按插排上的开关**。不经过 MCU、不经过软件，
正是协议第 5 条说的「物理急停」。

| 要求 | 现状 |
| --- | --- |
| 软件停止 | ✅ 演奏页「停止」+ 连接页 `急停` 按钮（发 `SAFE`，舵机全部断电、`armed=0`） |
| **物理急停** | ✅ **外接电源断电**（插排开关 / 拔插头） |
| 机械限位 | ✅ 连杆死点 |
| 软件限位 | ✅ 校准区间越界闸（`MOVE` 越界直接拒绝） |
| 可脱离结构 | ✅ 魔术贴绑带 —— 但**要在视频里主动演一遍** |
| 电流/温度保护 | ⚠️ 舵机自带过载保护，`STATUS` 可读电压/温度，无主动保护动作 |

拍摄要点（这段唯一容易拍砸的地方）：

- **用插排开关，别真去拔插头**：拔插头要两只手、镜头里动作不干净，而且每次都要重插。
  把**插排开关摆在能拍到、单手够得到**的位置。
- **必须在演奏进行中断**。静止时断电不叫"急停"，这一条甲方会盯。
- 断完紧接着演**可脱离**：解开魔术贴绑带、把手抽出来。
- 断电瞬间舵机即失力，手会"塌"下来 —— 这**正是要拍的证据**，别剪掉。
- ⚠️ 断电后舵机是自由状态，但连杆还挂在手指上。**先低速小幅度预演一遍**再正式拍，
  确认断电瞬间不会别到手指。

## 三、画质：现在"发灰、像黑白"，怎么调

你说「还是有点黑白的感觉」——这个症状很典型，按下面顺序排，**前两条中一条必中**。

### 3.1 第一嫌疑：色彩范围（limited / full）错配

这是"颜色还在，但整体发闷、黑不黑、白不白"的头号原因。

- 相机/采集卡输出的是 **YUV 有限范围**（黑=16、白=235），
  软件却按 **完整范围**（0~255）解释 → 黑被抬到 16（深灰）、白被压到 235（浅灰），
  对比度和饱和度一起被"压缩"，观感就是**灰蒙蒙、没颜色**。

**10 秒自检法**（建议拍前必做）：

1. 画面里同时放**一张白纸**和**一块黑布/黑鼠标垫**。
2. 录 5 秒，截图看取色值：
   - 白纸 ≈ **255**、黑布 ≤ **20** → 色彩范围正确。
   - 白纸只有 **220~235**、黑布在 **30~50** → **就是这个问题**，往下调。

**修法**：把相机（或采集软件）的**色彩范围/Quantization Range 设为 Full（0-255）**，
在 OBS 里是：`来源 → 视频采集设备 → 属性 → 配置视频 → 色彩范围`，
与相机实际输出对齐；USB 摄像头多数是 MJPEG，OBS 里**采集格式选 MJPEG 或 YUY2**，
不要选 NV12（部分驱动在 NV12 路径下会走错误的 range 转换）。

### 3.2 第二嫌疑：光照不足 + 自动曝光

你截图里是**桌面台灯/室内顶光**的典型结果：整体偏暗 → 相机自动曝光拉升增益 →
噪声上升、降噪介入抹平细节、白平衡乱跑、饱和度被拉低 → **灰**。

**补光方案（这是"自然"的关键，比调参数管用十倍）**：

```
        俯视相机（略高，俯 30~40°）
                 │
                 ▼
    [主光 45°]            [补光 60°]
     5600K                 5600K
     强度 100%             强度 40~50%
     柔光罩/硫酸纸          柔光罩
        ╲                    ╱
         ╲                  ╱
          ╲   ┌────────┐   ╱
           ╲  │ 手 + 手套│  ╱
            ╲ └────────┘ ╱
             ╲          ╱
              ▔▔▔▔▔▔▔▔▔▔
              深灰/黑桌面（吸光）
```

硬性要求：

- **两盏灯色温必须一致（都用 5600K，或都用 3200K），CRI ≥ 95**。
  一盏白光台灯 + 窗外自然光/顶灯，是偏色和发灰的头号来源。
- **把窗帘拉上，关掉顶灯**，只用摄影灯。混合色温下白平衡锁不住。
- 手下方垫**深灰或黑色**桌垫（深色吸光 → 主体更亮、立体感出来，画面立刻"有颜色"）。
- **背景清空**：你截图里左侧那些纸箱、纸板、面包板、散线，浅色杂物一多，
  相机测光就被拉灰。挂一块**深灰/藏青的布**或纯色背景纸，主体立刻就跳出来了。
- 灯不要正对镜头（会起雾发白），用柔光罩或隔一层硫酸纸。

### 3.3 相机参数（补光到位后，锁死这些）

| 参数 | 设定 | 为什么 |
| --- | --- | --- |
| 自动曝光 / 自动增益 | **关**，手动 | 验收视频要前后一致；自动曝光遇到黑色手套会突然拉亮 |
| 快门 | 1/60 ~ 1/100 s | 配合灯光；**60fps 拍摄时用 1/120**，同时确认灯不闪（频闪会拉横纹） |
| ISO / 增益 | 100~400 | 越低越干净；不够亮就**加灯，别加 ISO** |
| 自动白平衡 | **关**，手动 5200~5600K | 或对着白纸手动校白，直到白纸在画面里是中性白 |
| 饱和度 | **+15 ~ +25** | 直接对症"像黑白" |
| 对比度 | +8 ~ +12 | 补回被压平的层次 |
| 锐度 | +5 左右 | 适当，太高边缘会出现白边（对焦在连杆上会很明显） |
| 伽马 / Gamma | 1.0（不要调高） | 调高会把暗部抬灰，正是你要避免的 |
| 降噪 | 低 / 关 | 降噪是"发灰"的帮凶 |
| 逆光补偿 / 宽动态 HDR | **关** | 开着必定发灰 |
| 曝光补偿 | 0 或 -0.3 | 深色手套容易过曝，略降更好看 |

### 3.4 别踩的坑

- **不要开"低照度模式 / 夜视 / 灰度"**（部分 USB 摄像头在暗光下会自动切灰度）——
  先确认没有这个开关被打开。
- 不要用美颜 / 磨皮 / 滤镜（会破坏"画面能够辨认装置动作"这个基本要求）。
- 拍完**先看 10 秒试片再正式开录**，不要一次成片赌运气。

## 五、第 5 段（频率验收）的详细步骤 —— 这段是协议第 4 条的验收依据

协议原文：

> 动作频率的含义为：某一手指从初始位置下压后再抬回初始位置，计**一个完整周期**。
> 软件动作频率可从 **0 Hz（停止）** 开始设置；样机**实测最高可用频率不低于 2 Hz**，
> 具体最高值**以发货前视频在安全行程及样机负载工况下展示的测试结果为验收依据**。

三个关键词：**0 Hz 起可设**、**安全行程**、**样机负载工况**（= 必须戴在手上拍，不能空载）。

### 步骤

| 序 | 操作 | 发什么 | 看什么 | 时长 |
| --- | --- | --- | --- | --- |
| a | 演示 0 Hz = 停止 | 不发命令，静止 | 画面静止，字幕：`0 Hz = 停止` | 5s |
| b | 逐档升频（单指：食指，槽位 3） | `SWEEP 3 500 100 8000`<br>`SWEEP 3 1000 100 8000`<br>`SWEEP 3 2000 100 8000`<br>`SWEEP 3 3000 100 8000`<br>`SWEEP 3 4000 100 8000`<br>`SWEEP 3 4900 100 8000` | 手指往复越来越快；字幕标出当前档位频率 | 6 × 8s = 48s |
| c | **实测最高可用频率**（关键证据） | `RATE 3 0 0 100 5`（单指，100% 行程） | 屏幕打出<br>`RATE_DONE cycles=5 half_ms≈100 full_ms≈201 hz=4.97 slow_ms=… lost=0`<br>**给这个数字一个 5 秒特写** | 15s |
| d | 负载工况强化（可选但建议） | `RATE 0 0 0 100 3`（6 槽同时） | 六指一起动，`lost=0` 说明跟得上 | 15s |

> `SWEEP <slots> <freq_mHz> <depth%> <dur_ms> [speed] [acc]`，频率单位 **0.001 Hz**（`4900` = 4.9 Hz）。
> `RATE <slots> <speed> <acc> <depth%> [cycles]`，`0` = 全部槽位，`3` = 食指；
> `cycles` 是完整行程次数；**`RATE` 每个半程都等舵机真正到位才走下一个**，
> 所以 `hz` 是"这套机械实际能跑到的频率"，不是"命令发得有多快" —— 这正是协议要的口径。
> `lost` 必须为 **0**；不为 0 说明该档位实际跟不上，要如实报更低的数字。

### 怎么呈现最有力

- **b 段**证明"频率可设、可从 0 开始"；
- **c 段**给出"实测最高可用频率 4.97 Hz ≥ 2 Hz"这个**验收数字**；
- 屏幕上的 `hz=4.97` 和手上的动作**必须在同一帧里**（所以画中画很重要）；
- 字幕直接写结论：**`实测最高可用频率 4.97 Hz（要求 ≥ 2 Hz）`** ——
  别让甲方自己去算，帮他算好。

> ⚠️ 拍之前**必须实机复测一次**，确认当时真的是 4.97 Hz。
> 舵机刚换过线、校准跑过、电源电压不同，都会让这个数变。**以当天实测为准，不要照抄文档里的数。**
