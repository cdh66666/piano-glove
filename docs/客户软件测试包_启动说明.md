# 钢琴手套单 EXE 运行版使用说明

适用：带内置使用说明的原生单 EXE。具体版本以 EXE 文件版本、交付清单 SHA256 和程序内“设置 → 使用说明”为准。下面先给当前步骤；20261022 ZIP/BAT 的原说明仅在末尾历史区域保留。

1. 双击 `钢琴手套.exe`。**整个程序就这一个文件，不需要任何配套文件夹，也不需要另装 Python。** 界面组件、CP210x 驱动包、固件镜像和烧录工具都已打在程序里，拷到别的电脑上直接双击即可。PDF 转换可离线使用。
2. 需要训练或设备曲库时接 USB 数据线并按装置要求供电。缺 CP210x 驱动时点“安装驱动并连接”；驱动包已内置。Windows 若弹出管理员确认，需由使用者确认；取消或失败会显示实际结果。
3. 看到 USB COM 口和“已就绪”再操作。顶部“调试校准”打开完整调试台，“返回软件”回训练软件。相同主控不要同时由其他程序占用串口。
4. 使用结束先点“停止”，再关闭。关闭时提交当前 PDF 编辑并保存；保存失败按提示重试或明确处理未保存修改。打开或重连不恢复旧动作。

**换电脑/首装说明（R30 起）**：交付用的是完整离线单文件版，WebView2 界面组件的安装器已内置在程序里。程序启动时自己判断系统缺不缺组件，缺就自己装，不需要你另外准备 `MicrosoftEdgeWebView2RuntimeInstallerX64.exe`，也不需要把它和主程序放同一个文件夹。

以前那份"轻量版"（组件外置）只用于内部调试，不再对外交付——它才需要额外文件，也就是之前出现"单程序跑不起来、必须依赖某个文件夹"的原因。

装组件时 Windows 可能弹管理员确认，点"是"即可；取消或失败程序会显示真实结果。Windows 10 缺组件首装仍按实际验证记录判定。

## PDF、曲库和手机

拖入带右手印刷指法的 PDF，左键原地修改指法/时值/起拍，右键忽略/恢复。“上一待查/下一待查”可跨页定位。数据完整时可直接导出，无需重复确认每行；范围可选全部、行、页或自定义，速度按每首谱保存。缺印指法、扫描/不支持字体、复杂反复或无计量倚音仍可能需要人工处理。

`.pglpack` 包含曲谱与原谱，`.pgl` 为紧凑曲谱，复核 JSON 可备份后继续编辑。设备曲库须连接手套后上传/管理；原谱图保存在使用该包的电脑/浏览器，手套保存紧凑曲谱。声音开启后随曲谱时间轴播放，停止后静音；软件内音频证据不替代扬声器听感/延迟验收。

手机连接 `PIANO_GLOVE_…` 热点，使用系统弹页或“登录此网络”入口；电脑“设置 → 手机连接”提供二维码。热点小窗无法选文件时改用完整浏览器。手机页面由手套提供，不需要电脑保持运行；PDF 转换在电脑完成。弹页受手机系统影响；更新电脑 EXE 不等于更新手套固件。

## 文件与支持范围

电脑日志、校准记录、原谱和校对进度保存在当前用户 `%LOCALAPPDATA%\PianoGloveSoftware`；普通升级不要删除此目录。设备曲库保存在手套中，二者不同。

目标为 Windows 10/11 x64。已有成品运行证据来自 Windows 11；Windows 10、全新系统缺组件安装、客户电脑及真实手机仍按实际验证记录判定。完整说明和许可在程序内离线可用；源码维护与内部资料准备见[构建部署说明](DELIVERY-BUILD-AND-DEPLOY.md)。本说明不认定客户已验收或已付款。

## 钢琴手套客户运行版 · 20261022（历史）

解压整个文件夹，双击 **01-打开软件.bat**。无需安装 Python，使用时保留程序窗口。

## 第一次连接这台电脑

1. 主控接 USB 数据线，舵机按现有装置方式供电。
2. 缺少驱动时，顶部原连接按钮会变为 **自动安装并连接**，点一次即可。
3. Windows 弹出管理员授权窗口时确认“是”；之后下载、校验、安装、查找 COM 口和连接由程序处理。

正常已有驱动时直接连接，不重复安装。若接了多块主控，在页面选择实际使用的一块。驱动安装需要联网及电脑管理员权限；取消授权或安装失败时会显示真实结果。

需要安装的是 CP210x USB 串口驱动，不是舵机固件。USB 驱动问题无需给六台舵机重新编号或重新烧录。

## 调试、校准与使用

**02-调试和校准.bat** 打开完整调试台。编号中断时保持原接线，使用“继续编号（保留进度）”。已经编号的手套更换佩戴者时按页面重新测量舒适行程。

完成校准后，按需使用“手指训练”或“曲谱跟随”。电脑端 PDF 校对与读谱教程可在不连接主控时使用。用完先点“停止”，再关闭程序；重新连接不恢复旧动作。

PDF 识别针对支持的矢量谱，候选音符必须人工校对。确认右手指法与时值后再导出；推荐 `.pglpack`，曲谱和原谱图片可一起保存。识别候选数量不代表准确率。

速度条已加宽，拖动或点击百分比可展开放大精调条，按 1% 调整，也可用 ±1% 按钮或直接输入数字。

## 手机无线使用

本次配套固件将热点设为免密，并改进无线曲谱的短暂丢包重试与保活容忍。**手机端功能需要先由供应方通过源码版调试台“一键烧录”更新主控**；仅解压电脑运行包不会升级板内页面。

手机连接 `PIANO_GLOVE_...` 热点后，用普通浏览器打开 `http://192.168.4.1/software.html`。系统热点登录小窗可能不支持选文件，此时使用页面“选文件没反应？”里的地址，在正常浏览器选择 `.pgl` 或 `.pglpack`。写入前会检查曲谱格式与校验和。

## 打不开或仍没连上

- 网页未弹出：打开 `http://127.0.0.1:8123/software.html`。
- 点击页面的 **USB / 驱动帮助** 可查看进度与备用安装步骤。
- 无法检测到 USB：检查数据线与主控 USB 接入，充电线不能传输串口数据。
- 另一版本程序已占用端口：先退出旧程序，再启动本版。
- **03-运行文件自检.bat** 检查运行文件、PDF 与曲谱处理，不打开串口或启动动作。

本包适用于 Windows 10/11 64 位。包含客户软件及第三方许可；不包含 CAD、客户资料、校准轨迹或固件升级镜像。运行文件自检通过不代表所有客户电脑和手机均已实测。
