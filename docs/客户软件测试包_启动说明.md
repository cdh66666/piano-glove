# 钢琴手套客户运行版 · 20261021

解压整个文件夹，双击 **01-打开软件.bat**。无需安装 Python，使用时保留程序窗口。

## 第一次连接这台电脑

1. 主控接 USB 数据线，舵机按现有装置方式供电。
2. 页面显示缺少驱动时，点一次 **自动安装并连接**。
3. Windows 弹出管理员授权窗口时确认“是”；之后下载、校验、安装、查找 COM 口和连接由程序处理。

正常已有驱动时直接连接，不重复安装。若接了多块主控，在页面选择实际使用的一块。驱动安装需要联网及电脑管理员权限；取消授权或安装失败时会显示真实结果。

需要安装的是 CP210x USB 串口驱动，不是舵机固件。USB 驱动问题无需给六台舵机重新编号或重新烧录。

## 调试、校准与使用

**02-调试和校准.bat** 打开完整调试台。编号中断时保持原接线，使用“继续编号（保留进度）”。已经编号的手套更换佩戴者时按页面重新测量舒适行程。

完成校准后，按需使用“手指训练”或“曲谱跟随”。电脑端 PDF 校对与读谱教程可在不连接主控时使用。用完先点“停止”，再关闭程序；重新连接不恢复旧动作。

PDF 识别针对支持的矢量谱，候选音符必须人工校对。确认右手指法与时值后再导出；推荐 `.pglpack`，曲谱和原谱图片可一起保存。识别候选数量不代表准确率。

## 打不开或仍没连上

- 网页未弹出：打开 `http://127.0.0.1:8123/software.html`。
- 点击页面的 **USB / 驱动帮助** 可查看进度与备用安装步骤。
- 无法检测到 USB：检查数据线与主控 USB 接入，充电线不能传输串口数据。
- 另一版本程序已占用端口：先退出旧程序，再启动本版。
- **03-运行文件自检.bat** 检查运行文件、PDF 与曲谱处理，不打开串口或启动动作。

本包适用于 Windows 10/11 64 位。包含客户软件及第三方许可；不包含 CAD、客户资料、校准轨迹或固件升级镜像。本次软件更新不要求重新刷写已经适配的主控固件。
