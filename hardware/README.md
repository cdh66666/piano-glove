## 一、电气规格

| 项目 | 规格 |
| --- | --- |
| 主控板 | 微雪 **Servo Driver with ESP32**（SKU 21593）：ESP32 + **CP2102** USB 转串口 + OLED + WiFi + DC 6~12V 供电口 |
| PC ↔ 板 | USB-C（UART0），**固定 115200 8N1**。板载 CP2102，Windows 下出现为 `Silicon Labs CP210x`（实测 `VID:PID=10C4:EA60`） |
| 板 ↔ 舵机总线 | UART1，**GPIO18 = RX / GPIO19 = TX，1,000,000 bps**，TTL 半双工 |
| 舵机总线接线 | 3 线（GND / Vcc / Signal），全部舵机**并联在同一条总线**上 |
| 供电 | **5V/5A 适配器接 DC 圆口**（USB-C 只给板子供电，**不带舵机**） |
| 舵机数 | **6**（拇指 2 + 四指各 1） |
| 主控固件 | **自研 `PIANO_GLOVE_2`**（本仓库 `firmware/`）。原厂固件闭源、只做 ID 编号与手动校准，无串口透传能力，已弃用 |

> ⚠️ **DC 圆口电源必须接。** 只插 USB-C 时舵机没有动力电，表现为**全部 ping 不通** ——
> 很容易误判成"总线坏了"或"驱动问题"。

实测读数（2026-09 实机）：舵机反馈电压 `voltage_raw` **52~57** → **5.2~5.7V**（随电源与负载浮动，正常）；
舵机温度 **34~36 °C**；6 槽全部在线。

## 二、两套舵机：`STS3032` 与 `SC09`

这套手套换过舵机，**两套都能用**，但**不是混插**（见下面的警告）。

| 项 | **STS3032-C001**（当前在机上） | **SC09**（另一套） |
| --- | --- | --- |
| 飞特系列 | **SMS / STS 族** | **SCSCL 族** |
| 位置分辨率 | **12 位，0~4095** | **10 位，0~1023** |
| 转角范围 | 360° | 300° |
| 速度反馈 | **有** | **无**（只有位置、负载、电压） |
| 支持的控制模式 | 位置 / 速度 / PWM | **仅位置 + PWM** |
| 工作电压 | 4.8~6V | 4.8~6V |
| 出厂 ID | 全为 **1** | 全为 **1** |
| 接口 | TTL 半双工 | TTL 半双工 |

**怎么区分 / 怎么切档**：固件上电会自动读舵机自己的寄存器（型号 / 最小角 / 最大角）判断家族与量程，
`INFO` 里的 `profile=` 与 `range=` 就是结论；`PROFILE` 可随时查、`PROFILE AUTO` 可重新探测。
详见 [firmware/README.md](../firmware/README.md) 的「型号自适应」一节。

> ⚠️ **官方明确警告：不同系列不要挂在同一条总线上。**
> 所以「两套舵机」= **整条总线一起换**（6 个舵机全换成同一族），
> 不是"两种混着插、让固件自适应"。固件做的是**认家族**，不是**混协议**。
>
> ⚠️ **换档必须重新校准**：位置量程从 4095 掉到 1023，旧校准数据会落在错误的位置上。

演奏只用**位置控制**，所以 SC09 那套也够用（缺速度反馈不影响演奏，只影响"读速度"这类诊断）。

> **SC09 实机验证现状**：代码路径已按飞特官方 SDK 对齐，但**尚未在真机上跑过**
> （作者手上那套还没接上去）。接上后先跑 `PROFILE AUTO` + `PROFILE` 复核家族与量程，
> **再重新做一次校准**。

## 三、槽位 ↔ 舵机（固件默认映射）

| slot | 名称 | 角色 | 参与演奏 | 默认舵机 ID |
| --- | --- | --- | --- | --- |
| 0 | 拇指按压 | 把拇指压到琴键上 | ✔ | 1 |
| 1 | 拇指侧摆 | 演奏前把拇指摆到能压到键的位置（使能位） | ✘ | 2 |
| 2 | 食指 | 按压 | ✔ | 3 |
| 3 | 中指 | 按压 | ✔ | 4 |
| 4 | 无名指 | 按压 | ✔ | 5 |
| 5 | 小指 | 按压 | ✔ | 6 |

> ⚠️ **出厂贴的「拇指侧压 / 拇指下压」标签是反的**（2026-09-20 实机确认）：
> 真的把拇指**按下去**的是 **slot 0**，真的往**旁边摆**的是 **slot 1**。
> 调试台第 4 步可以一键对调角色（只换角色，**不换舵机 ID、不作废校准**）。
> 详见 [docs/design-notes.md](../docs/design-notes.md) §3.5。

## 四、机械

- **6 个舵机，但能独立按琴键的只有 5 根手指**：拇指那两根里只有一根真的按压，另一根只负责把拇指摆到合适位置（整场不动）；其余四指各 1 个舵机。
  **说"6 自由度"是按舵机数算的，说"能按琴键的手指"是 5** —— 两个口径别混。
- 传动方式：舵机臂 + 连杆，带动佩戴者的手指做上下按压。

**⚠️ 一个必须先想清楚的点**：舵机是**主动驱动**佩戴者的手指，所以
**机构的行程必须留余量** —— 顶到机械限位会直接顶伤手指或齿轮。
固件为此内置了校准区间越界闸（见 [firmware/README.md](../firmware/README.md)）。

## 五、已知硬件缺陷（历史）

**曾有 1 个舵机接触不良**：20 次 `PING` 仅 6 次通。
→ **已排除**（重新插接端子后恢复正常，现 6/6 稳定在线）。

同类问题的排查提示：接触不良时 `CAL AUTO START` 会被固件**直接拒绝**（它要求 6 槽全在线），
所以"校准起不来"的第一嫌疑就是**某根舵机的线**，而不是固件。
