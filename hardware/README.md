# hardware · 结构件与电路

## 电气规格

| 项目 | 规格 |
| --- | --- |
| 主控板 | 微雪 **Servo Driver with ESP32**（SKU 21593）：ESP32 + **CP2102** USB 转串口 + OLED + WiFi + DC 6~12V 供电口 |
| 舵机 | 6 × **Feetech STS3032-C001**：ST 系列、12bit 磁编码、量程 **0~4095**（360°）、工作电压 **4.8~6V**、出厂 ID 全为 1、TTL 半双工 |
| PC ↔ 板 | USB-C（UART0），**固定 115200 8N1** |
| 板 ↔ 舵机总线 | UART1，**GPIO18 = RX / GPIO19 = TX，1,000,000 bps** |
| 舵机总线接线 | 3 线（GND / Vcc / Signal），6 个舵机并联在同一条总线上 |
| 供电 | **5V/5A 适配器接 DC 圆口**（USB-C 只给板子供电，不带舵机） |
| 实测电压 | 舵机反馈 `voltage_raw=57` → **5.7V，正常** |

> ⚠️ DC 圆口电源必须接。只插 USB-C 时舵机没有动力电，表现为全部 ping 不通。

## 机械

- **6 自由度**：拇指 2 个舵机（一个下压、一个侧压），其余四指各 1 个
- **待补**：连杆 / 绳驱的具体传动方式、行程 80% 对应的舵机角度、3D 模型、BOM、装配说明

## 已知硬件缺陷

**有 1 个舵机接触不良**：20 次 `PING` 仅 6 次通。建议换线或重压端子后再装回手套 —— 否则 6 槽位无法全部在线，`CAL AUTO START` 会直接被固件拒绝。
