## 候选形态

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| Web + Web Serial | 跨平台零安装，调参界面开发快（`dual-n20-pot-motor-driver` 已验证） | 高采样率下浏览器吞吐受限，不适合长时间录制 |
| Python 桌面（PySide/Qt） | 采样与算法处理能力强，便于做标定与数据分析 | 需分发与环境管理 |
| 二者组合 | Web 做实时调参，Python 做离线分析与标定 | 需维护两套代码 |
