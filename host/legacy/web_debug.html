说明

拇指由 1 号(下压) 与 2 号(侧压) 两个舵机共同控制：只动 1 号 = 拇指正下方直按；1、2 号同时动 = 拇指斜向下按。 程序里 NOTE_ACTIONS 把 do 映射为只压 1 号、re 映射为 1+2 号协同，其余音符对应食/中/无/小指。
实机模式使用浏览器 Web Serial 直接读写 STS3032（请用 Chrome / Edge 打开本页，并允许串口访问）；模拟模式无需硬件，用于验证行程、节奏与可行性。
