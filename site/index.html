在自己的电脑连接手套

  1. 下载完整代码并解压。
  2. 安装 Python 3，安装时勾选 Add Python to PATH。
  3. 双击 host / start-debug.bat，打开本机调试台。
  4. 通过 USB 连接主控，按页面提示编号和校准。

公网预览不访问串口，也不会控制他人的手套。固件源码位于 firmware 文件夹。
